### 15. `thumbnails.$.tsx` 路径遍历 — 验证器与实际读取路径不一致 ⭐R36

- **文件**: `apps/web/app/routes/thumbnails.$.tsx` L19-29
- **代码**:
  ```ts
  const decodedPath = path.normalize(decodeURIComponent(filePath))
  const validation = pathValidator.validatePath(decodedPath)
  // ↑ validator 内部: resolve(THUMBNAILS_DIR, stripped) → 检查 startsWith(THUMBNAILS_DIR)
  // 但 stripped = decodedPath.replace(/^\/+/, '') → 对绝对路径 "/etc/passwd" 得到 "etc/passwd"
  // resolve(THUMBNAILS_DIR, "etc/passwd") → THUMBNAILS_DIR/etc/passwd → 通过检查！

  if (validation.isValid) {
    if (fs.existsSync(decodedPath)) {     // ← 用原始 decodedPath = "/etc/passwd"

  }
  ```
- **影响**: `GET /thumbnails/%2Fetc%2Fpasswd` → 验证器检查 `THUMBNAILS_DIR/etc/passwd`（通过），但 `fs.createReadStream("/etc/passwd")` 读取的是根目录下的文件
