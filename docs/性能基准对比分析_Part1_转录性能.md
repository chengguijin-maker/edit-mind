# 性能基准对比分析报告 - Part 1: 转录性能

## 报告概述

本报告是视频搜索/索引领域竞品调研的一部分（用户故事 US-007），专注于转录性能的深度对比分析。

**报告结构：**
- Part 1: 转录性能（本文档）
- Part 2: 视觉分析性能

## 1. 转录技术对比

### 1.1 主流转录引擎

| 引擎 | 提供方 | 准确率 | 速度 | 成本 | 语言支持 |
|------|--------|--------|------|------|----------|
| **Whisper** | OpenAI | 95-98% | 0.1-0.3x实时 | 免费（本地） | 99种语言 |
| **Deepgram** | Deepgram | 90-95% | 5-10x实时 | $0.0043/分钟 | 36种语言 |
| **AssemblyAI** | AssemblyAI | 92-96% | 3-5x实时 | $0.00025/秒 | 英语为主 |
| **Google STT** | Google Cloud | 90-95% | 2-4x实时 | $0.006/15秒 | 125种语言 |
| **Azure STT** | Microsoft | 90-94% | 2-3x实时 | $1/小时 | 100+语言 |
| **AWS Transcribe** | Amazon | 88-93% | 1-2x实时 | $0.024/分钟 | 31种语言 |

**关键发现：**
- Whisper 准确率最高，但速度最慢（CPU 模式）
- Deepgram 速度最快，但成本较高
- 本地部署（Whisper）vs 云 API 的权衡

### 1.2 Whisper 性能详解

#### 模型规模对比

| 模型 | 参数量 | VRAM | 准确率 | CPU速度 | GPU速度 |
|------|--------|------|--------|---------|---------|
| tiny | 39M | ~1GB | 85-90% | 0.05x | 2-3x |
| base | 74M | ~1GB | 88-92% | 0.08x | 3-5x |
| small | 244M | ~2GB | 92-95% | 0.1x | 4-6x |
| medium | 769M | ~5GB | 95-97% | 0.15x | 5-8x |
| large-v2 | 1550M | ~10GB | 96-98% | 0.2x | 6-10x |
| large-v3 | 1550M | ~10GB | 97-98% | 0.2x | 6-10x |

**速度说明：**
- 0.1x 实时 = 1小时视频需要10小时处理
- 6x 实时 = 1小时视频需要10分钟处理

#### GPU 加速效果

**RTX 3090 参考区间（公开 benchmark / 大模型场景）**：
```
如果使用更大的 Whisper 模型并启用 GPU：
- 单独转录阶段通常可达到数倍实时速度
- 10-15 分钟 / 小时音频属于公开资料中的激进参考区间
```

**需要特别说明**：
```
当前仓库默认模型是 medium，不是 large-v3
当前文档中的多 GPU 吞吐数字不能直接视为当前代码实测
端到端视频索引耗时也不能只用转录阶段外推
```

### 1.3 faster-whisper 优化

Edit Mind 使用 `faster-whisper` 库，相比原版 Whisper 有显著性能提升。

**优化技术：**
- CTranslate2 引擎（C++ 实现）
- INT8 量化（准确率损失 <1%）
- 批处理优化
- 内存管理改进

**性能提升：**
```
原版 Whisper large-v3 (GPU): 6-8x 实时
faster-whisper large-v3 (GPU): 8-12x 实时
提升幅度: 30-50%
```

**当前代码实现：**
```python
# python/services/transcription/model.py
self._model = WhisperModel(
    self.config.model_name,
    device=self.config.device,
    compute_type=self.config.compute_type,
    download_root=self.config.cache_dir,
)
```

补充说明：

- 当前代码默认模型来自 Python 服务启动参数，默认值是 `medium`
- 文档里不能把 `large-v3` 当作当前默认配置

## 2. 竞品转录性能对比

### 2.1 Edit Mind

**技术栈：**
- 引擎：faster-whisper
- 默认模型：medium
- 硬件：取决于实际部署机器
- 并发：可配置（默认1）

**当前可确认事实：**
```
- 代码默认使用 faster-whisper
- 当前默认模型是 medium
- 当前仓库未附带这套工作区可复现的实测 benchmark 输出
- RTX 3090 / large-v3 / 多 GPU 的公开数据只能作为参考区间
```

**成本：**
- 硬件成本：一次性投入（GPU）
- 运行成本：电费（~$0.50/小时，3x RTX 3090）
- 软件成本：免费（开源）

**优势：**
- 准确率最高（97-98%）
- 隐私保护（本地处理）
- 无使用限制
- 支持99种语言

**劣势：**
- 初始硬件投资高
- 速度相对云 API 较慢
- 需要技术维护
